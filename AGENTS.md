# OpenCode Agent Instructions

## Til va tushuntirish
- Foydalanuvchi bilan o‘zbek tilida, sodda va bosqichma-bosqich gaplash.
- Texnik ishlarni bajarishdan oldin rejani tushuntir.
- Fayllarni o‘chirish, paket o‘rnatish yoki katta o‘zgarish qilishdan oldin ruxsat so‘ra.
- Ish bajarilgach, natijani tekshir.

## Loyiha
- Bu loyiha Telegram AI Agent yaratish uchun.
- Ishni boshlashdan oldin `TASK.md` va kerakli loyiha fayllarini tekshir.
- Mavjud kodni tushunmasdan qayta yozma.

## Obsidian xotirasi
- Obsidian xotira ombori: `D:\AI_Agent_Project`
- Loyiha haqidagi uzoq muddatli ma’lumotlarni shu ombordagi Markdown fayllaridan izla.
- Tegishli xotira fayllarini o‘qib, joriy vazifaga kerakli ma’lumotlardan foydalan.
- Yangi, kelajakda kerak bo‘ladigan loyiha qarorlari va bajarilgan ishlarni xotiraga yozishdan oldin foydalanuvchiga rejangni ayt.
- Xotiraga maxfiy ma’lumotlarni yozma.
- Agar xotira papkasiga kira olmasang, buni ochiq ayt; kirgandek ko‘rsatma.
- Xotira fayllarini o‘zgartirishdan oldin tegishli mavjud ma’lumotlarni tekshir va keraksiz takrorlarni yaratma.

## Xavfsizlik
- `.env`, API kalitlari, bot tokenlari va parollarni hech qachon xotira fayllariga yoki kod ichiga joylama.
- Maxfiy ma’lumotlarni terminal natijalari va loglarda oshkor qilma.
- Tashqi papkalardagi fayllarni o‘zgartirishdan oldin ruxsat so‘ra.

## Ish jarayoni
1. Vazifani tushun.
2. `TASK.md` va kerakli kodlarni tekshir.
3. Qisqa reja ber.
4. Kerakli o‘zgarishlarni bajar.
5. Test yoki tekshiruv o‘tkaz.
